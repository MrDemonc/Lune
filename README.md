## 📖 About This Project

This repository hosts the official GitHub Pages website for the **Lune** music player project. It provides users with a clean, responsive portal to discover features, download the latest APK releases, access F-Droid builds, view community contributors, and support the project through donations.

### ✨ Key Features

- **Responsive Design**: Fluid layout tailored for both desktop and mobile devices.
- **Light & Dark Theme**: Elegant espresso and warm light-coffee palettes with automatic system preference detection.
- **Dynamic Release Updates**: Automatically fetches latest version notes, dates, and direct APK download links via GitHub API.
- **Animated Wave Background**: Lightweight canvas wave animation responding to theme changes.
- **Donations & Community**: Quick support links (PayPal, Ko-fi, Monero XMR) and live contributor credits.
